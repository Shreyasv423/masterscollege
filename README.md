# Masters PU College Hassan — Official Web Portal

> **Exceptional Education. Exceptional Value. Personal Education, Extraordinary Success.**  
> Official modern web application for **Masters PU College Hassan** (Managed by Masters Education Trust, Regd. 2012–13), Vivekanagara, Hassan, Karnataka.

---

## 🏛️ About the Institution
Masters Pre-University College is one of the premier science institutions in Karnataka, consistently securing **State Top 5** positions and maintaining **District Top 5** rankings every year since its inception in 2012. The college offers integrated Pre-University Science programs (**PCMB** & **PCMCs**) combined seamlessly with day-to-day competitive exam coaching for **NEET, IIT-JEE (Mains & Advanced), K-CET, BITSAT, NDA & NATA**.

---

## ✨ Features & Architecture

- **Clean & Prominent Branding**: Minimalist navigation header featuring the official high-resolution college crest with zero clutter.
- **Dynamic Campus Hero Slider**: High-definition interactive carousel featuring actual campus facilities and event photography.
- **Institutional Profile & Leadership**: Comprehensive coverage of founding vision, mission, aims, and department heads for Physics, Chemistry, Mathematics, and Biology.
- **Academic Programs & Competitive Coaching**: Detailed syllabus overviews and career gateways for PCMB & PCMCs combinations.
- **Interactive Campus Facilities**: World-class Science Laboratories, Library & Reading Rooms, Student Mentorship Cell, Audio-Visual Conference Room, 24/7 Security, Transport Fleet, and Residential Hostels with click-to-enlarge lightbox viewing.
- **Achievers & Sports Wall of Fame**: District and International champions in Football, Karate (Dubai), Athletics, and Netball alongside Board and JEE topper banners.
- **Interactive Examination Results Explorer**: Searchable and filterable database containing **424+ verified student records** across KCET Ranks, PU Board Distinctions, NEET Qualifiers, and JEE Achievers with pagination.
- **Interactive 17-Field Online Admission Application**: Full admission form matching official requirements with client-side validation, localStorage persistence, and instant generation of printable/downloadable **Application Acknowledgment Slips** with unique reference IDs (`MPC-2026-XXXX`).
- **Campus Gallery & Video Tour**: Category-filtered photography and virtual campus walkthroughs.
- **Contact & Campus Location**: Inquiry forms, direct phone/WhatsApp trigger buttons, and embedded Google Maps for Vivekanagara, Hassan.
- **Institutional Privacy Policy & Cookies**: Compliant, frosted-glass Cookie Consent Banner and detailed Educational Records & Student Data Protection Policy.
- **Comprehensive SEO & Structured Data**: Integrated Schema.org `CollegeOrUniversity`, `EducationalOccupationalProgram`, and `BreadcrumbList` JSON-LD schemas, Geo tags, Open Graph, Twitter Cards, `robots.txt`, and `sitemap.xml`.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Shreyasv423/masterscollege.git

# Navigate to the project directory
cd masterscollege

# Install dependencies
npm install
```

### Development Server
```bash
# Start local development server with Hot Module Replacement (HMR)
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### Production Build
```bash
# Validate code formatting & lint rules
npm run lint

# Compile production bundle
npm run build

# Preview production build locally
npm run preview
```
